About Me

Computer Science • Data Analysis • Low-Level Systems & Security

Technical Background

I am a Computer Science and Data Analysis student at King Faisal University (KFU), set to graduate in February 2027, with a dedicated focus on low-level software development, reverse engineering, Windows internals, binary analysis, and software security.

My work revolves around dissecting compiled binaries, analyzing execution flow at the instruction level, understanding operating system internals, and evaluating security architectures. I routinely apply both static and dynamic analysis methodologies to explore how software behaves, how protections are implemented, and where security boundaries can be strengthened.

Research Philosophy

I approach software security through rigorous empirical verification: examining the assembly instructions, reconstructing data structures, and validating execution pathways in isolated environments. The goal of this site is to maintain an open, structured archive of technical write-ups, analysis findings, and utility code for fellow researchers and low-level engineers.
