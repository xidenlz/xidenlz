Malware Triage: Uncovering a Quasar RAT Disguised as a Game Cheat

Author: Musaed
Published: 2026
Category: Malware Triage / Threat Intelligence

Incident Overview

During routine community file moderation, an archive submitted under the guise of an operational game cheat was flagged for in-depth inspection. Attackers routinely weaponize game security communities by masquerading remote access trojans (RATs) as legitimate cheats, capitalizing on users who are accustomed to disabling AV real-time protection to run unverified software.

Static disassembly and behavioral sandbox analysis confirmed that the submitted package was a multi-stage decoy concealing a Quasar RAT payload communicating over Portmap infrastructure.

Verdict

DO NOT APPROVE / MALICIOUS: Multi-tier social engineering payload containing decoy GUI binaries, a Go-compiled dropper, and an active Quasar RAT connecting to an external dynamic C2.

Multi-Stage Component Analysis

1. Decoy DLL (Visual Basic)

Static inspection of the included dynamic-link library revealed that it was compiled in Visual Basic. Decompilation showed that the file consisted entirely of dummy graphical components (checkboxes, comboboxes, and layout frames) with zero functional hooks, memory reading routines, or game interaction logic. Its sole purpose was to serve as visual camouflage during surface-level user inspection.

2. Secondary Binary (136 KB C++ Stub)

The second executable (136 KB, compiled in C++) functioned as an intermediate dummy loader. String analysis of the main entry point revealed unreferenced hash strings and obfuscated metadata designed to pad the binary and distract automated heuristic parsers.

3. Primary Payload: Run.exe (Go Dropper)

The third binary, Run.exe, exhibited multiple severe anomalies:

  • Language & Runtime: Compiled in Go. While Go is common in modern malware development for cross-platform evasion and binary bloat, it is extremely atypical for low-level game modifications.
  • File Size & Entropy: Large packed footprint with high entropy sections.
  • Multi-Engine Detection: VirusTotal initial scan returned a 17/71 detection ratio, triggering heuristic alerts for generic trojan droppers.

Infrastructure & Network Indicators (IOCs)

Behavioral network analysis and DNS query logs revealed that Run.exe immediately attempted resolution of:

Network IOC C2 Domain & Port Forwarding 
Domain:   ramsadaye-38594.portmap.io
Service:  Portmap.io (TCP Tunneling / Port Forwarding)
Context:  Subdomain prefix matched uploader handle registered 5 days prior

Portmap.io is frequently leveraged by threat actors to route inbound C2 traffic through TCP tunnels without requiring port forwarding on their home ISP. Cross-referencing community metadata revealed the uploader account had been registered just five days prior, with this being their first submission.

Dynamic Sandbox Execution (Any.Run)

The binary was executed in an isolated Any.Run interactive sandbox environment to observe process tree spawning, memory injection, and network socket activity.

  • Payload Classification: The memory dumped from the spawned subprocess matched known YARA signatures and configuration structures for Quasar RAT (.NET-based open-source remote access tool).
  • Capabilities Identified: Keystroke logging, remote desktop streaming, credential theft from web browsers, and reverse shell execution.

Indicators of Compromise (IOCs)

Artifact Type Details / Classification
Run.exe SHA256 / File Go-compiled Quasar RAT dropper (17/71 on VirusTotal).
ramsadaye-38594.portmap.io Domain / C2 Dynamic TCP tunnel used for remote C2 command traffic.
Decoy.dll File (VB) Empty graphical user interface shell.

Conclusion & Remediation

The submission was permanently rejected and blocked, preventing deployment to end users. This triage underscores the necessity of combining static binary triage (compiler detection, section parsing) with automated dynamic sandbox analysis and infrastructure threat correlation.
