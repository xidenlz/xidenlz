Kernel & User Injection Framework C++17 / NT Native API / Driver

NtInjector (NtLoader)

An advanced Windows injection framework operating exclusively through direct NT Native API calls with zero Win32 API wrappers and zero static IAT entries. All function pointers are resolved dynamically at runtime via PEB walking and a custom export resolver. Features modular JSON-driven configuration (ntcfg.json) supporting user-mode and kernel-mode execution paths.

Supported Injection Primitives
  • Manual Map: In-memory PE mapping with base relocations, import resolution, TLS callbacks, and SEH handling without registering in the PEB module list. Includes optional header and section zeroing (.pdata, .rsrc, .reloc).
  • LdrLoadDll Stub: Writes an LDR_DATA struct and stub into the target, executed via NtCreateThreadEx.
  • User-Mode APC Queue: Enumerates threads via NtQuerySystemInformation and queues LdrLoadDll via NtQueueApcThread to fire on alertable waits.
  • Kernel Driver (NtKrnl): Dispatches injection via a custom driver (\??\NtKrnldrv) with automated driver unload upon completion.

Graphics Hooking & Anti-Cheat Research C++ / MinHook / GDI

Screenshot Detection Bypass

A specialized Windows graphics hooking utility that intercepts screen capture routines (BitBlt in gdi32.dll). Demonstrates how anti-cheat and security capture routines can be hooked to return clean framebuffers to detection scanners while preserving active overlays in testing environments.

Core Capabilities
  • BitBlt Interception: Hooks gdi32!BitBlt to filter overlay layers from screen capture buffers.
  • Internal Hook & Test Suite: Includes an internal DLL hook engine and a standalone target testing dummy application.
  • Broad Compatibility: Applicable to anti-cheat screenshot routines (PunkBuster, FairFight, Ricochet) utilizing GDI capture mechanisms.

Binary Analysis & Triage Suite Python & C++ / Zydis Engine

PE Analyzer Suite

A specialized binary analysis and moderation framework engineered for automated sample triage, embedded binary extraction, and instruction-level disassembly. Features dedicated tooling across Windows and Linux platforms:

Suite Components Tool Architecture 
├── pe_analyzer.py          # Windows PE triage & embedded payload extraction
├── pe_analyzer_linux.py    # Linux PE/ELF triage & symbol inspection
└── pe_analyzer.exe         # Zydis-based instruction analysis & GetProcAddress tracing
Core Capabilities
  • Embedded Binary Extraction: Identifies nested executable files (.exe, .dll, .sys) inside host binaries and accurately dumps them by calculating the exact raw Offset & Size.
  • Heuristic & Rule Scanning: Inspects section entropy anomalies and scans string tables for external C2 indicators, Discord webhooks, port-forwarding tunnels, and loader markers.
  • Zydis Assembly Disassembly: High-throughput x86/x64 instruction parsing in C++ to trace dynamic import resolution and locate calls to GetProcAddress in obfuscated samples.
